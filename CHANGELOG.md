# Changelog

All notable changes to Aura are documented in this file.

## [1.1.0] - 2026-06-05

### Added

- Premium app shell flow with splash, onboarding, and auth-first entry.
- Home dashboard upgrades with proactive insights and workload visibility.
- Smart scheduling assistant and routine templates.
- Guided `Plan My Week` flow with draft generation, review, and one-tap apply.
- Actionable reminders with snooze and smart reminder messaging.
- Collaboration improvements with invite audit events, conflict filters, and one-tap conflict resolution.
- Release readiness and reliability tools in Settings:
- Data integrity sweep
- Notification rebuild utility
- Release readiness checklist

### Improved

- Session handling and server account management UX.
- Railway sync discoverability and household sync workflows.
- Family photo assets and onboarding presentation quality.

### Operational

- Added release smoke automation script: `scripts/release_smoke.sh`.
- Added manual QA sign-off checklist: `docs/RELEASE_QA_CHECKLIST.md`.

## [1.0.0] - 2026-06-04

### Added

- Initial Aura baseline app structure and backend sync scaffolding.
