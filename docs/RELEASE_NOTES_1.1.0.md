# Aura 1.1.0 Release Notes

Aura 1.1.0 focuses on making the app feel like a complete premium family planner, while also hardening it for real-world use.

## Highlights

- Premium app shell with splash, onboarding, and account-first setup.
- Rebuilt Home dashboard with insights, proactive recommendations, and richer day planning.
- Smart scheduling assistant with conflict-aware slot suggestions.
- Guided `Plan My Week` assistant with generated draft events and one-tap apply.
- Actionable reminders with snooze and smarter event messaging.
- Collaboration upgrades with share audit history, conflict filters, and shared-event conflict repair.
- Reliability tools for release readiness:
- Data integrity sweep
- Notification rebuild utility
- Release readiness checks in Settings

## Notable user-facing improvements

- Family workload balance and streak insights surfaced on Home.
- Reusable routine templates for common family tasks.
- Better account and household sync discoverability in Settings.
- Improved family photo presentation and onboarding polish.

## Release status

- Automated smoke checks: passed
- Signing-free iOS build: passed
- Unsigned archive generation: passed
- Manual device QA and signed archive: still required before final GA publication
